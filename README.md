# 汪汪队ETF跟踪器(自建版)

宽基 ETF 成交额与资金动向监控 — 判断今日国家队(汇金)是否通过宽基ETF进场。

**页面**: https://nailx.github.io/etf-watchdog/

## 架构

| 层 | 内容 |
|---|---|
| 实时行情 | 腾讯 `qt.gtimg.cn` 批量接口(外盘/内盘/成交额/份额, 无认证) |
| 历史基线 | 新浪 `quotes.sina.cn` 日K(20日均额=量×均价) + 5分钟K(48时点日内分布曲线, 支撑盘中"同时点对齐") |
| 快照生成 | `update_data.py` 交易时段每2分钟生成 `data/snapshot.js`(含服务端判定结论) |
| 前端 | 单静态页 `index.html`, 60秒自刷新, 点表头排序 |

## 指标口径

- **同时点倍数** = 当前累计成交额 ÷ (20日均额 × 该时点历史平均已走完比例), 解决"半天除全天"不可比问题
- **主动净买入** = (外盘−内盘)÷(外盘+内盘)×成交额, 逐笔方向推算, **非资金净流入/非申赎数据**
- **判定**: 🟠 净买≥40亿 或 300系≥25亿 或 (≥1.8x且净买≥15亿); 🔴 净买≥90亿 或 300系≥50亿
- 汇金持仓列为 2025 年报前十大持有人口径(2026-03 后已不再披露, 属绝版静态标签)

## 本地运行

```bash
python3 update_data.py           # 生成快照(含缓存刷新)
python3 update_data.py --push    # 有变化且距上次>5分钟时 git push
```

